## Justice

Justice is a static webpage built using HTML, CSS, and Tailwind CSS.
The page is designed for a legal solutions service, presenting a professional and clean layout suitable for clients looking for legal assistance.

Live Website: https://rakib120822.github.io/legal-solution/

### 📝 Project Overview

Justice is a static homepage for a legal services website.
It highlights the services offered and provides a professional introduction to the firm.

### Sections included:

Hero/banner section
Legal Practive Area
Client Say
Frequently Asked Any Questions
Contact Us Form
Footer

Services or practice areas overview

Footer with contact and social links

The page emphasizes clarity, professionalism, and ease of navigation.

### 🛠️ Technologies Used

HTML5

CSS3

Tailwind CSS

### 🚀 How to Use

Clone the repository:

git clone https://github.com/rakib120822/legal-solution.git


Navigate to the project folder:

cd legal-solution


Open index.html in a browser to view the homepage.
